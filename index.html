Etch pre-sale promise tracker

What Etch sold, and what shipped

In September 2024, Kevin Geary's company, Digital Gravy, pre-sold Etch for WordPress at up to $1,299, with no refunds, before it existed. This page lists what that pre-sale promised and where each promise stands now.

Last checked against Etch's own pages: 6 November 2026. I recheck every month.

Still on Etch's website

These are on etchwp.com today, and Etch's own docs or release notes say otherwise.

  1. Dropped, still sold

    Everything you build is saved as core WordPress blocks

    The pricing page says Etch "writes everything you build to core WordPress blocks" for "full data liberation". Etch's docs say it uses "custom Gutenberg blocks (not core blocks)". Its blog said: "We tried to make core blocks behave. They wouldn't."

    The full storyEtch docsEtch blogPricing page

  2. Not delivered

    WooCommerce integration

    It was on the two top pre-sale tiers. Every plan still lists it, with an asterisk: "not currently available, but are planned for the near future". There are no shop elements.

    The full storyPricing page

  3. Two of six

    "Replaces 6+ premium plugins"

    That line is on every plan. The FAQ on the same page says "Etch will eventually replace" them. I count two of the six named categories as replaced.

    The full storyPricing page

  4. Late, page not updated

    A production-stable V1 in September 2025

    The pricing FAQ still says "Etch V1 will be production stable in September 2025". Version 1.0 is dated 30 January 2026.

    The full storyEtch 1.0 changelog

Not delivered

  1. Doesn't exist

    A marketplace for third-party add-ons

    The pre-sale FAQ said "Etch will have a marketplace where third party developers can create add-ons for Etch". The $799 tier got 40% off it and the $1,299 tier got 50%. There's no marketplace, and the word isn't on Etch's home, features or pricing pages.

    The full story

  2. Not delivered

    No more SEO plugins

    Etch has no SEO panel. Version 1.7.0 added "Yoast SEO and Rank Math compatibility", which means working alongside SEO plugins.

    The full storyEtch 1.7.0 changelog

  3. Partly

    No more ACF or custom field plugins

    Etch's docs call its built-in fields "more of a playground right now than a real part of your workflow (unless your needs are very basic)". Relationship fields still need ACF or Meta Box.

    The full storyEtch docs

  4. Partly

    No more performance plugins

    Etch handles images. I found no caching, script management or preloading.

    The full storyEtch docs

  5. Not delivered

    Version control

    Listed on the agency plans with the same asterisk: "not currently available".

    The full storyPricing page

  6. Not delivered

    Native faceting (built-in filters)

    Etch's docs say "Coming soon...".

    The full storyEtch docs

  7. Not delivered

    Mixins, the infinite canvas and "Sketches"

    None of them are in the builder.

    The full story

The timeline

  1. Missed

    Large sites and e-commerce by the end of year two

    The pre-sale timeline put large sites and e-commerce in year two, which ended in September 2026. There's no native WooCommerce, and Etch's docs call its fields a playground.
